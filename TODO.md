# DEVELOPMENT RULES

1. Не выполнять сразу несколько крупных Phase.
2. Сначала закончить текущую Phase.
3. После реализации запускать проект.
4. Проверять результат, а не просто наличие кода.
5. Не отмечать задачу `[x]`, пока она реально не работает.
6. Не удалять выполненные задачи.
7. Если обнаружена новая проблема — добавить её в TODO.
8. Если задача больше текущей Phase — не реализовывать её преждевременно.
9. Не добавлять новые игровые механики без изменения `GAME_DESIGN.md`.
