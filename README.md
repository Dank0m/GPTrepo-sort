# Sort & Upgrade

Браузерная 2D-игра на HTML5 Canvas и TypeScript. Постоянное мастерство, ежедневные задания, опциональная rewarded-реклама и сохранение прогресса через Яндекс SDK.

Это конвейерная версия (лента слева направо, жизни, сессионный магазин). Требования: [`GAME_DESIGN.md`](./GAME_DESIGN.md). План: [`TODO.md`](./TODO.md).

## Запуск

```bash
npm ci
npm run build
npm run preview
```

Открыть **http://localhost:47321**.

Для разработки: `npm run dev` (тот же порт).

Локально SDK Яндекса нет — игра работает без рекламы. Для проверки UI наград используйте `npm run dev` и `?mockAds=1`. В production-сборке этот параметр отключён. SDK загружается динамически с `/sdk.js`; локальный 404 ожидаем и не мешает запуску.

## Правила

- Перетащи предмет в контейнер своего типа.
- Верный дроп: монеты × комбо, частицы и звук.
- Ошибка или съезд с ленты: −1 жизнь, комбо сбрасывается.
- Полный контейнер: предмет возвращается на ленту без штрафа.
- Кнопки внизу: скорость, ценность, тип (до 3 новых фигур: ромб, звезда, гекс), автосорт, буфер. До конца сессии. Цены: `база × 2.5^уровень` (скорость 30 / 75 / 188 / 469, и так далее).
- Если **все** контейнеры полные — заполнение сбрасывается, джекпот `120 × (число типов)²` и анимация «Полный набор». При доступной рекламе — опционально удвоить джекпот.
- Конец сессии: нажми, чтобы начать заново. В новую партию переносится **10%** монет (округление вниз). Реклама не продолжает партию.
- В магазине при доступной рекламе — «Монеты за рекламу»: ролик → +500, кулдаун 90 с.
- Динамик в углу HUD выключает звук. Кнопка паузы рядом (ещё **Esc** / **P**). Рядом с ними — флаги **RU | EN**: нажми, чтобы переключить язык. Выбор запоминается. На Яндексе язык сначала берётся из SDK. Клавиша **D** — debug overlay (только dev).
- Лучший счёт и комбо помнятся после обновления страницы; на Яндексе ещё уезжают в cloud save.

## Мастерство и задания дня

- Игра начинается с экрана правил и целей; до нажатия «Начать сортировку» лента стоит.
- Каждая верная ручная сортировка даёт 2 XP. Полный набор — 20 XP. Автосорт не фармит XP за фигуры и ручные задания.
- Уровень: `1 + floor(sqrt(XP / 100))`. Новый уровень добавляет 10 стартовых монет в каждой партии (максимум 100). Вместе с ними при повторной партии остаются прежние 10% монет.
- Каждый UTC-день: 30 ручных фигур (+75 XP / 150 монет), 12 ручных фигур подряд без ошибок (+100 XP / 200 монет), один полный набор (+125 XP / 250 монет). Награды начисляются сразу, один раз за день.
- Прогресс заданий сохраняется между партиями. Новые задания появляются в 00:00 UTC. Штрафов за пропуски нет.
- Кнопка мастерства над лентой открывает прогресс и ставит игру на паузу. Escape закрывает окно. Уровень, XP, задания и рекорды сохраняются при перезагрузке. На этом устройстве восстанавливаются также монеты, улучшения, жизни, комбо и заполнение контейнеров; продолжение начинается на паузе со свежей лентой. Постоянные рекорды/мастерство дополнительно синхронизируются через облако SDK; текущая партия хранится только локально.
- При наличии нескольких устройств объединяются максимальные значения, а не сумма: это исключает повторное начисление наград, но не объединяет независимые офлайн-сессии в общий итог.

## Проверки и публикация

Node.js 24 (для встроенного запуска TypeScript-тестов), npm 11.

```bash
npm ci
npm test
npx playwright install chromium
npm run test:e2e
npm run build
npm run preview
```

В облачной Linux-среде уже установлен Chromium:

```bash
CHROMIUM_PATH=/usr/lib/chromium/chromium npm run test:e2e
```

На Windows используйте обычный `npm run test:e2e` после установки браузера Playwright.

Архив для загрузки должен содержать файлы **из `dist`**, с `index.html` в корне. В PowerShell:

```powershell
Compress-Archive -Path .\dist\* -DestinationPath .\sortup-yandex.zip -Force
```

Чек-лист, результаты и ограничения аудита: [YANDEX_PUBLICATION.md](./YANDEX_PUBLICATION.md).
