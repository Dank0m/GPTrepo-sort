# Sort & Upgrade

Браузерная 2D-игра на HTML5 Canvas и TypeScript. Сейчас **PHASE 7**: слой Яндекс SDK, опциональная rewarded-реклама, cloud save рекорда.

Это конвейерная версия (лента слева направо, жизни, сессионный магазин). Требования: [`GAME_DESIGN.md`](./GAME_DESIGN.md). План: [`TODO.md`](./TODO.md).

## Запуск

```bash
npm install
npm run build
npm run preview
```

Открыть **http://localhost:47321**.

Для разработки: `npm run dev` (тот же порт).

Локально SDK Яндекса нет — игра идёт как раньше, кнопок рекламы нет. Для проверки UI наград: **http://localhost:47321/?mockAds=1** (только отладка, не для продакшен-архива).

## Правила

- Перетащи предмет в контейнер своего типа.
- Верный дроп: монеты × комбо, частицы и звук.
- Ошибка или съезд с ленты: −1 жизнь, комбо сбрасывается.
- Полный контейнер: предмет возвращается на ленту без штрафа.
- Кнопки внизу: скорость, ценность, тип (до 3 новых фигур: ромб, звезда, гекс), автосорт, буфер. До конца сессии.
- Если **все** контейнеры полные — заполнение сбрасывается, джекпот `120 × (число типов)²` и анимация «Полный набор». При доступной рекламе — опционально удвоить джекпот.
- Конец сессии: можно посмотреть рекламу и продолжить с 1 жизнью (один раз), либо начать заново.
- В магазине при доступной рекламе — FREE COINS: ролик → +500, кулдаун 90 с.
- Динамик в углу HUD выключает звук. Кнопка паузы рядом (ещё **Esc** / **P**). Рядом с ними — флаги **RU | EN**: нажми, чтобы переключить язык. Выбор запоминается. На Яндексе язык сначала берётся из SDK. Клавиша **D** — debug overlay.
- Лучший счёт и комбо помнятся после обновления страницы; на Яндексе ещё уезжают в cloud save.
