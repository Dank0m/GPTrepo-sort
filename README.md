# Sort & Upgrade

HTML5 Canvas / TypeScript / Vite. Ветка `cursor/conveyor-prototype-b9e9`, версия игры 1.1.1: постоянное дерево навыков и ограниченная экономика.

## Запуск

Node.js 24, npm 11.

```bash
npm ci
npm run dev
```

Порт 47321. Production: `npm run build`, затем `npm run preview`. Оба сервера используют один порт — запускайте по очереди. Vite `base: "./"` обязателен для версии игры в подпапке Яндекса; SDK `/sdk.js` намеренно абсолютный. Без SDK игра работает локально, рекламы нет. `?mockAds=1` поддерживает только dev-проверку удвоения полного набора; в production отключён.

## Управление и прогресс

ЛКМ или палец: фигура → контейнер той же формы и цвета. Ошибка/пропуск отнимает жизнь. Полный набор контейнеров очищает их за 36–72 монеты. Новые фигуры учитывают заполнение и уже выпущенные предметы.

Локальный прототип: каждые 20 верных сортировок игра останавливается на экране дерева улучшений. Купить навык можно только в перерыве. «Далее» начинает следующий уровень; Escape, клик по полю и платформенный resume не обходят этот экран. Пауза и отложенное предложение рекламы полного набора сохраняются при reload. Сложность ограничена десятой сменой, но перерывы продолжаются каждые 20 фигур.

На игровом поле остаются только изученные навыки и связи между ними. Иконки и линии выглядят как тонкие прорези в поверхности, без покупок или неоткрытых узлов. Подробности и полный выбор навыков доступны в окне между уровнями. Текущие ZIP в downloads относятся к опубликованной в Git версии 1.1.1; этот вариант находится в отдельной ветке cursor/level-breaks-engraved-skills; новый архив публикации пока не собирался.

Широкий захват первоначально закрыт. Купите «Разделители 1» за 40 и «Широкий захват 1» за 100. После этого ПКМ переносит группу из зоны 220px; второй уровень увеличивает её до 300px. На телефоне используйте кнопку группы: включите режим и захватите фигуры пальцем. Подходящие заполнят контейнер, остальные вернутся на ленту без штрафа.

Уникальные навыки: магнитное доведение, досрочная разгрузка полного контейнера нажатием с наградой 8 монет, двойной автосорт, сервисное замедление после набора и возврат пропуска с перезарядкой. Все цены, эффекты и расчёт дохода: [docs/ECONOMY.md](docs/ECONOMY.md).

Комбо — счётчик ручной серии, а не множитель дохода. Базово 3 монеты, бонус не более +1. Полное развитие повышает базу до 5 и бонус до +3. Автосорт даёт 1–2 монеты и не увеличивает комбо. Рекламной кнопки выдачи фиксированных монет нет; оставлено добровольное удвоение полного набора.

После проигрыша сохраняются навыки и мастерство. В новую партию переходят 10% монет, максимум 20, плюс до 10 монет мастерства. Текущая партия сохраняется на устройстве после действий; reload восстанавливает её на паузе со свежей лентой. Постоянное дерево и рекорды дополнительно синхронизируются через SDK. Объединение дерева берёт максимум каждого навыка; деньги текущей партии между устройствами не синхронизируются.

Автоматическая сложность: каждые 20 правильных сортировок начинается следующая смена, до десятой. В паузе, рекламе и меню нет хода игры. Динамик включает mute; Escape/P ставит паузу. RU/EN переключаются флагами, исходный язык из SDK. Fullscreen запрашивается по пользовательскому действию.

**Миграция:** старые монеты, рекорд монет и сессионные улучшения версии 1.0 не переносятся из-за прежнего неограниченного дохода. XP, мастерство, задания и рекорд серии сохранены. Новые покупки постоянные.

## Проверки

```bash
npm test
npx playwright install chromium
npm run test:e2e
npm run test:release
node scripts/economy-report.ts
```

В облачной среде для браузерных проверок: `CHROMIUM_PATH=/usr/lib/chromium/chromium` перед npm-командой. `test:release` собирает production и проверяет игру во вложенном пути `/558807/test-version/`, включая реальные действия указателем и сохранение.
