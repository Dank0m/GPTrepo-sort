# Sort & Upgrade

Браузерная 2D-игра на HTML5 Canvas и TypeScript. Сейчас **PHASE 3**: сортировка даёт монеты и комбо, ошибки и съезд с ленты тратят жизни. Апгрейдов нет.

Требования: [`GAME_DESIGN.md`](./GAME_DESIGN.md). План: [`TODO.md`](./TODO.md).

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который выведет Vite (по умолчанию `http://localhost:47321`).

Собранная версия (Preview в облаке использует её):

```bash
npm run build
npm run preview
```

## Правила

- Перетащи предмет в контейнер своего типа.
- Верный дроп: монеты × текущее комбо (10, 20, 30…).
- Неверный дроп или предмет уехал за край: комбо сбрасывается, −1 жизнь.
- 3 жизни. После нуля — клик, чтобы начать сессию заново.

## Структура

```
src/
  main.ts              точка входа
  config.ts            фаза, типы, экономика
  core/                canvas, цикл, ввод
  game/                мир, предметы, контейнеры
  render/scene.ts      сцена
  render/hud.ts        монеты, комбо, жизни
  debug/overlay.ts     debug HUD
```
