# Sort & Upgrade

Браузерная 2D-игра на HTML5 Canvas и TypeScript. Сейчас **PHASE 6**: пауза, рекорды, звук без фокуса.

Это конвейерная версия (лента слева направо, жизни, сессионный магазин). Требования: [`GAME_DESIGN.md`](./GAME_DESIGN.md). План: [`TODO.md`](./TODO.md).

## Запуск

```bash
npm install
npm run build
npm run preview
```

Открыть **http://localhost:47321**.

Для разработки: `npm run dev` (тот же порт).

## Правила

- Перетащи предмет в контейнер своего типа.
- Верный дроп: монеты × комбо, частицы и звук.
- Ошибка или съезд с ленты: −1 жизнь, комбо сбрасывается.
- Полный контейнер: предмет возвращается на ленту без штрафа.
- Кнопки внизу: скорость, ценность, тип (до 3 новых фигур: ромб, звезда, гекс), автосорт, буфер. До конца сессии.
- Если **все** контейнеры полные — заполнение сбрасывается, джекпот `120 × (число типов)²` и анимация «Полный набор».
- Динамик в углу HUD выключает звук. Кнопка паузы рядом (ещё **Esc** / **P**). Клавиша **D** — debug overlay.
- Лучший счёт и комбо помнятся после обновления страницы.
